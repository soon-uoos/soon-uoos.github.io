    저장 상태

    저장은 현재 브라우저에만 적용됩니다. GitHub 공개 사이트에는 자동 배포되지 않습니다. 데이터 손실 방지를 위해 JSON 백업 파일도 보관하세요.

    불러오기

    이전 버전에서 만든 작품, 도면, CV, 메인 문구와 디자인 설정을 복원합니다. 복원 전에 현재 편집기의 백업 파일을 자동으로 다운로드합니다.

    01 / 기존 파일 선택

    이전 편집기에서 ARCHIVE TOOLS → Export JSON backup으로 내려받은 파일을 선택하세요. 과거에 발행한 공개용 index.html에서도 데이터를 추출할 수 있습니다.

    02 / 복원 방식
    불러올 파일을 선택해 주세요.
    이전 작업이 파일 목록에 없나요?

    이전 HTML 편집기는 작품을 HTML 파일 내부가 아닌 브라우저 저장소에 저장했습니다. 새 파일에서 자동으로 보이지 않는 경우, 이전에 작업하던 편집기와 브라우저에서 JSON 백업을 다운로드해야 합니다. 예전 편집기 파일만 선택해서는 다른 브라우저의 저장소를 읽을 수 없습니다. 과거에 공개용 HTML을 내보냈다면 그 파일에서도 복원할 수 있습니다.
